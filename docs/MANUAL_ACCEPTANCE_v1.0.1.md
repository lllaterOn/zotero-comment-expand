# v1.0.1 发布验收记录

## 变更范围

本版本只更新 Zotero 插件管理页中的中文描述，并同步补丁版本号和发布记录。插件名称保持为 `Zotero Comment Expand`；运行代码、插件 ID、更新地址和 Zotero 兼容范围均未变更。

## 验证结果

- `npm run verify` 完成类型检查、自动测试、仓库与更新清单检查、确定性 XPI 构建、发布资产关卡自测和安装包契约检查。
- 标签工作流生成的原始 XPI 和 `SHA256SUMS` 将在正式发布前下载并核对版本、清单内容和 SHA-256。
- 本次未在 Zotero 实机中重新安装或验收 `v1.0.1`。维护者已明确授权本次仅含显示元数据的版本在自动验证和发布资产校验通过后直接正式发布。
- `v1.0.0` 已完成的 Windows、Zotero 10.0.2、PDF 阅读器实机验收记录仍适用于未发生变化的运行功能，不代表对 `v1.0.1` 安装包进行了新的实机验收。
