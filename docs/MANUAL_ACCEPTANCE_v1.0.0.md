# v1.0.0 验收

维护者于 2026-09-17 确认当前版本功能和界面已满足要求，可以正式发布。

## 实机范围

- Windows，Zotero 10.0.2，PDF 阅读器。
- 评论/译文展开与恢复原生显示功能通过维护者手工使用确认。
- 评论按钮固定在原生搜索左侧的布局经过维护者复测确认；与 Bilingual Outline 同时使用。
- 工具条保持单行，其他插件的独立横向滚动行为保留。

EPUB、网页快照和其他操作系统尚未单独完成实机验收。全局偏好、初始化与关闭时序、重挂载、搜索节点保留及停用清理有自动测试覆盖；不将自动测试等同于所有平台的实机验收。

## 发布检查

- `npm run verify`：类型检查、15 项行为测试、仓库与更新清单、构建、发布资产正反路径和包检查通过。
- 正式版本化过程未改变已验收的启动与运行代码。
- 正式安装包及 SHA256 由标签工作流生成，发布前再次核对资产清单、版本与运行代码。
- 只发布当前正式版本，不公开本地试验配置、文献或过程产物。
